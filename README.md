# op

Pro Next.js 14 Web Application & License Key API hosted on Vercel for `Launcher.exe`.

## Features
- **Admin Dashboard**: Generate keys (1 Day, 7 Days, 30 Days, 365 Days, Lifetime), reset HWIDs, pause/delete keys.
- **Vercel API (`/api/validate`)**: High-speed live HTTPS endpoint for C++ `Launcher.exe`.
- **C++ Client**: Pro Win32 GDI+ Unicode Loader GUI.
